# CityFeedback Bot

Универсальный бот для сбора обратной связи от граждан через ВКонтакте. Позволяет создавать системы мониторинга различных аспектов городской жизни, собирать жалобы и предложения, а также управлять процессом их обработки.

## Основные возможности

### Для пользователей
- 📸 Загрузка фотографий с описанием проблемы
- 📍 Указание местоположения через геолокацию или текстовый адрес
- 📝 Создание обращений с автоматической нумерацией
- 🔔 Получение уведомлений об изменении статуса обращения
- 📱 Удобный интерфейс с кнопками и подсказками

### Для администраторов
- 👥 Групповой чат для координации работы
- 📊 Система отслеживания статуса обращений
- ✅ Возможность отмечать обращения как "в работе" и "исполнено"
- 📈 Экспорт данных в CSV для анализа
- 📋 История изменений статусов обращений

## Технические детали

### Системные требования
- Python 3.7 или выше
- Доступ к API ВКонтакте
- Достаточно места для хранения фотографий и логов

- pandas==2.1.4

- python-dateutil==2.8.2

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/SSHINRATENSSEI/cityfeedback-bot.git
cd cityfeedback-bot
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
venv\Scripts\activate     # для Windows
pip install -r requirements.txt
```

3. Создайте файл `.env` в корневой директории проекта:
```env
# Токен доступа к API VK
VK_TOKEN=your_vk_token_here

# ID группы ВКонтакте
GROUP_ID=your_group_id_here

# ID группового чата для администраторов
GROUP_CHAT_PEER_ID=your_chat_id_here

# Настройки логирования
LOG_LEVEL=INFO
LOG_FORMAT=%(asctime)s - %(name)s - %(levelname)s - %(message)s
```

## Настройка

1. Создайте группу ВКонтакте:
   - Перейдите в раздел "Управление сообществом"
   - Включите Long Poll API
   - Получите токен группы в разделе "Работа с API"
   - Запомните ID группы

2. Создайте групповой чат для администраторов:
   - Создайте беседу в ВКонтакте
   - Добавьте бота в беседу
   - Получите ID беседы (peer_id)

3. Настройте права доступа:
   - Убедитесь, что бот имеет права на отправку сообщений
   - Проверьте доступ к API для работы с фотографиями
   - Настройте права на создание бесед

## Использование

### Запуск бота
```bash
python bot.py
```

### Работа с обращениями

1. Пользователь начинает диалог с ботом:
   - Отправляет команду "Начать"
   - Получает приветственное сообщение
   - Выбирает действие (фото/обращение)

2. Создание обращения:
   - Загрузка фотографии (опционально)
   - Ввод текста обращения
   - Указание адреса или геолокации
   - Получение номера обращения

3. Администрирование:
   - Получение уведомлений в групповом чате
   - Изменение статуса обращений
   - Отслеживание прогресса

### Структура данных

Все обращения сохраняются в `data/reports.csv` со следующими полями:
- ticket_number: Номер обращения
- date: Дата создания
- user_id: ID пользователя
- photo_filename: Путь к фото
- message: Текст обращения
- address: Адрес или геолокация
- status: Статус обращения
- last_modified_by_id: ID администратора
- last_modified_by_name: Имя администратора
- last_modified_date: Дата изменения статуса

## Структура проекта

- `bot.py` - основной файл бота
- `models.py` - модели данных и состояния
- `storage.py` - работа с хранилищем данных
- `keyboards.py` - клавиатуры для взаимодействия
- `group_chat.py` - работа с групповым чатом
- `logger.py` - система логирования

- `data/` - директория для хранения данных
- `logs/` - директория для логов
